# metadocencia: Documentos con la Identidad Visual de MetaDocencia

Distribuye una extensión de Quarto con la identidad visual de
MetaDocencia (colores, tipografías y logo definidos en un único archivo
'\_brand.yml') y formatos para reportes HTML, reportes PDF, notas y
presentaciones RevealJS. Incluye funciones para crear documentos,
diagnosticar y actualizar la identidad en documentos existentes, y
aplicar la paleta institucional a gráficos de 'ggplot2'.
